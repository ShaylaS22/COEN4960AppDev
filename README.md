# JukeBox #
## How to use Sheet Music Reader ##
1. Launch colab.ipynb from Google Colab.
2. Run all code blocks up until the one that says to upload an image.
3. Make sure your Android is connected to the same Wi-Fi as the device currently hosting the local server.
4. Upload an image from the Sheet Music Activity, and it should generate a musicxml, and immediately take you to the transcriptor activity.
